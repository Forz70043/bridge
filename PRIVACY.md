# Privacy Policy for Bridge 🌉

**Last Updated: March 22, 2024**

This Privacy Policy explains how **Bridge** ("the Application") handles information.

## 1. No Data Collection
Bridge is a local management tool for Windows Subsystem for Linux (WSL). 
- **Personal Data:** The Application **does not** collect, store, or transmit any personal information, identity data, or contact details.
- **Telemetry:** There is no built-in telemetry or tracking system.
- **Usage Data:** We do not monitor which Linux distributions you use or how often you use the app.

## 2. Local Execution
All operations performed by Bridge (Start, Stop, Import, Export, etc.) are executed locally on your machine using the standard `wsl.exe` tool. No data is sent to external servers or third parties.

## 3. Permissions
The Application requires "Full Trust" permissions only to interact with the Windows Subsystem for Linux via the command line. These permissions are used exclusively for managing your local distributions.

## 4. Third-Party Services
Bridge does not integrate with any third-party analytics, advertising, or cloud storage services.

## 5. Contact
If you have any questions regarding this policy, you can open an issue on the official GitHub repository.

# Informativa sulla Privacy per Bridge 🇮🇹

**Ultimo aggiornamento: 22 Marzo 2024**

Questa Informativa sulla Privacy spiega come **Bridge** ("l'Applicazione") gestisce le informazioni.

## 1. Nessuna raccolta di dati
Bridge è uno strumento di gestione locale per Windows Subsystem for Linux (WSL).
- **Dati Personali:** L'Applicazione **non** raccoglie, memorizza o trasmette alcuna informazione personale o dato identificativo.
- **Telemetria:** Non è presente alcun sistema di telemetria o tracciamento integrato.
- **Dati di Utilizzo:** Non monitoriamo quali distribuzioni Linux utilizzi o quanto spesso usi l'app.

## 2. Esecuzione Locale
Tutte le operazioni eseguite da Bridge (Avvio, Arresto, Import, Export, ecc.) avvengono localmente sulla tua macchina tramite lo strumento standard `wsl.exe`. Nessun dato viene inviato a server esterni o terze parti.

## 3. Permessi
L'Applicazione richiede i permessi di "Full Trust" esclusivamente per interagire con WSL tramite riga di comando. Questi permessi sono usati solo per gestire le tue distribuzioni locali.

## 4. Servizi di Terze Parti
Bridge non integra alcun servizio di analisi, pubblicità o archiviazione cloud di terze parti.

## 5. Contatti
Se hai domande riguardo questa informativa, puoi aprire una issue sul repository ufficiale GitHub.
